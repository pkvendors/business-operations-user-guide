
# 8. Reports

## 8.1 Overview

The Reports module provides access to business
and operational reporting.

## 8.2 Generating a Report

1. Navigate to the Reports module.
2. Select the report type.
3. Enter the required search criteria.
4. Select **Generate Report**.
5. Review the report results.

## 8.3 Exporting a Report

1. Open the generated report.
2. Select **Export**.
3. Choose the available file format.
4. Save the exported report.

**Note:** Available export formats depend on
the application's configured functionality.
