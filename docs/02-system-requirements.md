
# 2. System Requirements

## 2.1 Overview

Users must have access to a supported device
and internet connection to use BOMS.

## 2.2 Software Requirements

| Requirement | Description |
|---|---|
| Operating System | Windows or macOS |
| Browser | Chrome, Edge, Firefox, Safari |
| Internet | Reliable internet connection |
| Account | Valid BOMS user account |

## 2.3 User Access

Users must have an active account and
appropriate system permissions.

## 2.4 Important Information

Contact your system administrator if you
experience access or compatibility issues.
