
# 7. Project Management

## 7.1 Overview

The Project Management module allows authorized
users to maintain project information.

## 7.2 Creating a Project

1. Navigate to Project Management.
2. Select **Create Project**.
3. Enter the project name.
4. Enter the project description.
5. Assign a project manager.
6. Enter the project start date.
7. Enter the expected completion date.
8. Select **Save**.

## 7.3 Updating Project Information

1. Search for the project.
2. Open the project record.
3. Select **Edit**.
4. Update the required information.
5. Select **Save**.
